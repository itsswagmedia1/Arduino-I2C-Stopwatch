# User Guide: Arduino I2C Stopwatch

Welcome to the Arduino I2C Stopwatch project guide. This document provides operating instructions and troubleshooting steps for the hardware prototype.

## 🕹️ How to Operate

### 1. Powering On
* Connect the Arduino Uno to a laptop using the USB cable, or power it via a 9V DC barrel jack adapter.
* Upon boot, the LCD will initialize, turn on its backlight, and display:
  ```text
  Stopwatch Ready
  Time: 00:00:00
